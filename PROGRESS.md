## How the site is built now (read this after a compaction)

- Edit `partials/*.html` and `css/src/*.css`, then `npm run build` (= `node scripts/build.mjs`). Pages hold include regions `<!-- include:x -->…<!-- /include:x -->` that the build fills. `cta-band` keeps page copy in `<!-- slot -->`.
- Work rows: `partials/work-<slug>.html`, generated by `node scripts/redesign/projects.mjs` (also regenerates the 4 new case-study pages: next-edge-realty, aj-agritech, qflow, somallamma-temple — DON'T hand-edit those, edit the script).
- Serve: `node scripts/serve.mjs 8123` (honours vercel.json redirects, 404.html). Screens: `MSYS_NO_PATHCONV=1 node scripts/review-shots.mjs <template>=<route>` (Git Bash mangles `/paths` without MSYS_NO_PATHCONV). Captures: `node scripts/capture-sites.mjs`.
- Templates: body class `t-<template>`; hero classes `hero dark|plate|paper [compact]`; sections `.section[.dark] > .wrap > .section-head + .section-body[.wide]`.
